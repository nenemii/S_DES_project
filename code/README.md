# S-DES 算法实现与测试

本项目完成《信息安全导论》作业 1，使用 Python 3 标准库实现 S-DES 的加密、解密、ASCII 多分组扩展、暴力破解和密钥碰撞分析，并提供 Tkinter 图形界面。

## 运行环境

- Python 3.10 或更高版本
- 无需安装任何第三方库

## 快速开始

在本目录打开终端后执行：

```powershell
python app.py
```

程序采用深色实验室风格顶部标题、浅色卡片式工作区和四个功能标签页：

1. **第 1 关：基本测试**：输入 8 位二进制明文（或密文）与 10 位密钥进行加/解密，同时显示 K1、K2。
2. **第 3 关：ASCII 扩展**：加密 ASCII 文本为以空格分隔的 8 位二进制密文；将其粘贴回来即可解密。
3. **第 4 关：暴力破解**：输入一个或多个“明文 密文”对，程序遍历全部 1024 个密钥并计时。
4. **第 5 关：碰撞分析**：固定一个明文，统计全部密钥的输出，展示不同密钥加密到同一密文的实例。

更详细的操作步骤请阅读 [用户指南](docs/用户指南.md)，实现结构和二次开发方式请阅读 [开发手册](docs/开发手册.md)。

## 自动测试与结果演示

```powershell
python -m unittest discover -s tests -v
python demo_results.py
```

测试覆盖密钥扩展、单分组已知向量、256 个分组的加解密互逆性、ASCII 扩展、暴力破解和密钥碰撞。

## 关键约定

- 所有二进制输入均使用字符串，例如 `10101010`，避免整数转换时遗漏前导零。
- ASCII 扩展模式只接受 ASCII（0~127）字符。密文显示为 8 位二进制组，以便不同语言/平台直接复制做交叉测试。
- SBox₂ 以作业图片中的备注为准，不使用其他课件或网络材料中的不同版本。
